# 奖池抽奖功能说明

## 功能概述

奖池抽奖是一个全新的抽奖玩法，所有未中奖的金币都会累积到奖池中，中奖者将获得奖池中的全部金币。投入的金币越多，中奖概率越高！

## 使用方法

### 1. 查看奖池信息
```
奖池信息
查看奖池
```
显示当前奖池金币数量和玩法说明。

### 2. 参与奖池抽奖
```
奖池抽奖 <金币数量>
奖池 <金币数量>
```
例如：
- `奖池抽奖 100` - 投入100金币参与抽奖
- `奖池 500` - 投入500金币参与抽奖

## 概率机制

中奖概率由两部分组成：

1. **基础概率**：5%
2. **金币加成**：根据投入金币与奖池金币的比例计算
   - 加成计算：`(投入金币 / 奖池金币) × 100`
   - 最高加成：45%
   - 总概率范围：5% - 50%

### 示例

假设当前奖池有1000金币：

- 投入50金币：概率 = 5% + (50/1000)×100 = 5% + 5% = **10%**
- 投入100金币：概率 = 5% + (100/1000)×100 = 5% + 10% = **15%**
- 投入500金币：概率 = 5% + (500/1000)×100 = 5% + 50% = **50%**（达到上限）

### 特殊情况

- 当奖池为空时，金币加成计算方式为：每100金币增加5%概率，最高45%

## 中奖规则

### 中奖
- 获得奖池中的**全部金币**（包含本次投入）
- 奖池清空，重新开始累积

### 未中奖
- 投入的金币进入奖池
- 为下一位玩家增加奖池金币

## 与普通抽奖的区别

| 特性 | 普通抽奖 | 奖池抽奖 |
|------|---------|---------|
| 中奖奖励 | 投入的2-3倍 | 奖池全部金币 |
| 概率机制 | 递增式（10%起，每次+5%） | 金币比例式（5%-50%） |
| 金币流向 | 系统生成/回收 | 玩家间循环 |
| 风险程度 | 较低 | 较高 |
| 收益潜力 | 固定倍数 | 取决于奖池大小 |

## 策略建议

1. **观察奖池**：奖池金币越多，中奖收益越大
2. **计算概率**：投入更多金币可以显著提高中奖概率
3. **风险控制**：不要投入超过自己承受能力的金币
4. **时机选择**：奖池金币较多时参与，收益更高

## 技术实现

### 数据模型

#### Prize_Pool 表
- `id`: 主键（固定为1，全局唯一）
- `total_gold`: 奖池总金币数

#### Daily_Sign 表（新增字段）
- `lottery_probability`: 普通抽奖概率

### 核心方法

- `Prize_Pool.prize_lottery()` - 执行奖池抽奖
- `Prize_Pool.get_pool_gold()` - 查询奖池金币
- `get_prize_award()` - 奖池抽奖业务逻辑
- `get_prize_pool_info()` - 获取奖池信息

### 概率计算公式

```python
base_probability = 5.0
if pool.total_gold > 0:
    gold_ratio = cost_gold / pool.total_gold
    bonus_probability = min(gold_ratio * 100, 45.0)
else:
    bonus_probability = min(cost_gold / 100 * 5, 45.0)

probability = base_probability + bonus_probability
```

## 注意事项

1. 投入的金币无法退回
2. 未中奖的金币会进入奖池，供其他玩家抽取
3. 中奖后奖池会清空
4. 建议根据自己的金币数量合理投入
